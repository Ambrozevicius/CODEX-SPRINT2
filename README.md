# 📱 Camera App — Interface de Câmera Mobile
 
## 📖 Sobre o Projeto
 
Este projeto consiste em uma interface de câmera de celular desenvolvida utilizando:
 
- HTML5
- CSS3
- JavaScript
 
O objetivo é simular um aplicativo de câmera moderno, inspirado nas câmeras de smartphones Android, contendo diversos modos de captura, configurações avançadas e uma interface responsiva.
 
---
 
# 🚀 Tecnologias Utilizadas
 
- HTML5 → estrutura da aplicação
- CSS3 → estilização e responsividade
- JavaScript → funcionalidades e interações
